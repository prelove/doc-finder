## C 索引一致性、可见性与生命周期

当前资源/新鲜度改进ad363da已独立复验，结论CHANGES_REQUESTED，尚未验收。重点补齐恢复文件重新入库、当前结果自动刷新、手动轮询与并发隔离，以及扫描/清理的跨生命周期资源约束；详见 [目标复验报告](analysis/2026-10-25-resource-goal-review.md)。B已验收版本不因此重开。

建议拆为稳定同步与异步解析两个change，避免大重构不可验收。

C1：新目录注册自身及子树、目录整体迁入补扫、删除子树、OVERFLOW/无效WatchKey对账、冷启动对账；网络快照含目录及扫描完整性，离线/权限/部分失败不推断未确认删除，失败写不保存成功快照。
C2：元数据先写、正文有界队列补齐；任务带版本防删除后复活/覆盖新内容；显示解析等待/失败/截断；索引代次与来源覆盖状态；再独立评估原子重建切换。
验收草案：目录新建→立即写文件、重命名/移动/删除、丢事件补扫；断网/部分拒绝访问/写失败后不误删且恢复可补齐；旧解析不得复活删除或覆盖更新。记录可复现故障注入与延迟。
依赖：A字段规则；与B可在共享writer/query接口稳定后分工。当前只查索引不承担实时同步SLA。
