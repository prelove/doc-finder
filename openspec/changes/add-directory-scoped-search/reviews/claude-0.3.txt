F-015（P2）桌面SearchWorker在service=null时静默空结果与D3/D8冲突

D8和6.2应逐一列出并统一后台入口/sequence，A5a evidence附全仓创建点搜索，避免漏1431。

F-017（P3）ParseException新行为影响常见输入
用户已确认取舍。以前C++、report (final类输入空结果，现在400；UsageGuide说明，并确认addToHistory不记录错误。

F-018（P3）固定隔离两细节

F-019（P3）离线/部分失败也造成陈旧记录

Windows手输e:\docs若按原字符串会Custom；应规范比较，DirectoryScopePanelTest加例。

每来源各commit，第二个失败时已有提交但服务可能仍null；只要有效commit，无论整体成功都尝试恢复服务，保留失败提示。
