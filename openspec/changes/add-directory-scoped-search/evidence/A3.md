## 改动文件

- 新增 `search/SearchException.java`（嵌套 `Code`，八个枚举值，(Code,String)/(Code,String,Throwable)，`getCode()`）
- 修改 `LuceneSearchService.java`：
  - 新构造 `LuceneSearchService(Path, IndexSettings, SourceRootProvider)`；旧构造默认 `new SourceManager()::loadSearchRoots`
  - `resolveScopedDirectory`：顺序为 空词短路 → `normalizeDirectory`（非法→INVALID_DIRECTORY）→ provider 单次快照（IOException→SOURCE_CONFIG_UNAVAILABLE）→ 覆盖判定 `equals || startsWith(descendantPrefix)`（不覆盖→DIRECTORY_NOT_INDEXED）
  - `addDirectoryFilter`：`(path_scope==D AND kind==folder) OR PrefixQuery(path_scope, descendantPrefix(D))` 以 FILTER 加入，Top-N 之前
  - 非 FOLDER 模式改为查询内 `MUST_NOT kind=folder`（类型过滤前移，修复高分目录占用 limit 的旧缺陷——属 D4 有意纠正）
  - `detectMatchType` 只解释关键词查询（不再带 FILTER），防 POSIX 目录名含 `name:` 误标
  - `ParseException`→INVALID_QUERY（有/无目录一致，WARN 记录）；`IndexNotFoundException`→INDEX_UNAVAILABLE；其余 IOException/RuntimeException→SEARCH_FAILED；不再吞成空列表；finally release
- 测试：新增 `DirectoryScopedSearchTest`（10）、`DirectorySourceValidationTest`（3，经真实 `new SourceManager(cfg).loadSearchRoots()` 读临时 sources.txt）
