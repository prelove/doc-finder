## 场景覆盖（小夹具断言）

- 中段字面：`report`→`AnnualReport2026.PDF`；CJK `支付`；单字 `报`；补充平面 U+1F4CA；符号 `spring-core`（按字面非语法）；大小写不敏感。
- 多词 AND：`annual report`/`report 2026` 只命中同时含两词的名称。
- 分档：整名 4 > 前缀 3 > 中段 2（常量分断言），同分切片内 (score→name 长度→path)。
- ALL 双列表：名称列整体先于排他正文列；name+content 文档只出现一次且标 `name+content`；仅正文文档标 `content`（解释不含 MUST_NOT 排他条件）。
- 冻结路径：CONTENT 不返回仅名称命中；EXACT `annualreport` 不中 `AnnualReport2026.PDF`、整名 term 仍命中；显式 `*report*` 通配与 FOLDER 范围不变；目录限定在字面路径生效。
- 截断：limit+1 探测，limit=3→TRUE/3 条、limit=5→FALSE/5 条、limit=6→FALSE；默认包装 UNKNOWN；HTTP UNKNOWN 省略 `hasMore`/`truncated`、已知值布尔对一致；limit clamp 200。
- 输入上限：>16 词或单 token >64 码点 → INVALID_QUERY。
- 遗留清理：`search/query/QueryBuilder`、`QueryExecutor` 零生产引用，已删除。
